# Smart Cofrinho

App Flask que usa a câmera do celular + Gemini API para reconhecer dinheiro (notas/moedas de Real) e somar num saldo.

## Como rodar

1. Clone o repositório
2. Crie um ambiente virtual e instale as dependências: pip install -r requirements.txt
3. Copie `.env.example` para `.env` e coloque sua chave do Gemini
4. Rode: python app.py
5. Escaneie o QR code exibido no terminal com o celular (mesma rede Wi-Fi)
